YouTube checking…

Fully automatic posting needs a one-time OAuth setup. Four steps, about 15 minutes — the full click-by-click walkthrough is in SETUP-YOUTUBE.md:

  1. Create a free Google Cloud project, then enable YouTube Data API v3.
  2. Create an OAuth client ID (Desktop app, or Web application — both work).
  3. Paste the client ID + secret into the API keys card on this screen.
  4. Add the redirect URI below in Google Cloud, then press Connect.
